# Implementation research — 24 October 2026

This developer document is not bundled into the website.

- [REA](https://github.com/wolfcatalyst/reverse-engineer-anything), npm `rea-agents@6.7.0`, was run against the existing local `dist` bundle. Evidence `ev_788f5ab6c28750b0755973f4cbd0b745ecffa69dfc691237ff3a95d0d056725d` is retained locally in ignored `data/private/rea-analysis.json`. It reconstructed the existing JavaScript artifact graph. It did not establish proprietary features or predictive trading accuracy. No third-party binaries or paid screener code were copied.
- [cot_reports](https://github.com/NDelventhal/cot_reports) was reviewed for the CFTC annual archive URL structure and report families. The project's parser is an independent standard-library implementation, reads members in memory, and bounds expanded size. It does not use unrestricted extraction.
- [forfac](https://github.com/janickfarrell/forfac) was reviewed as a scheduled calendar collection example. Our parser reads the public page's JSON `days` array using `JSONDecoder`, never executes embedded JavaScript, and retains actual/forecast/revision fields. Three normal requests cover last/current/next week. A denied page is not bypassed.
- [OpenBB calendar reference](https://docs.openbb.co/odp/python/reference/economy/calendar/) was reviewed for provider separation. OpenBB is not a runtime dependency and its data-license terms do not grant redistribution rights to this project.
- [GitHub schedule limitations](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule) prevent an exact 10-minute or real-time uptime guarantee.

The implementation uses deterministic release comparisons and mapped positioning, not a trained forecast model. No backtest or claimed predictive accuracy has been fabricated. Feed health, actual publication times and missing-data states are preserved.


## Coverage expansion

- The [official CFTC reporting portal](https://publicreporting.cftc.gov/stories/s/r4w3-av2u) and its `/api/views/{id}.json` metadata were checked for the seven datasets: `gpe5-46if`, `yw9f-hn96`, `72hh-3qpy`, `kh3c-gbw2`, `6dca-aqww`, `jun7-fc8e`, `4zgm-a668`. Live supplemental rows mix field-name casing despite metadata casing; the adapter normalizes keys before category mapping. Report overlap is excluded from the score.
- [FX Blue's public calendar](https://www.fxblue.com/calendar) exposes dated releases and linked history pages for the twelve supplemental currencies. The collector decodes server-rendered JSON strings, follows only validated release identities on the same host, and never runs embedded JavaScript. It scales K/M/B/T values explicitly, retains zero revisions and series identity, and retrieves previous values from the release's own page. It never shifts historical actuals to invent previous values.
- The public Nasdaq calendar was probed and compared with [OpenBB's provider implementation](https://github.com/OpenBB-finance/OpenBB/blob/develop/openbb_platform/providers/nasdaq/openbb_nasdaq/models/economic_calendar.py). Some duplicate entries omit periodicity, so it was not adopted for bias scoring. A direct FXStreet endpoint required authentication; no access control was bypassed.
- The asset sensitivity model is transparent code in `scripts/asset_models.py`. Higher growth and tighter monetary conditions are separate channels. Correlations and expected returns have not been estimated; a macro backdrop must not be represented as token-specific evidence.

## Historical and crypto research layer

- [BIS bulk downloads](https://data.bis.org/bulkdownload) supply monthly policy rates and year-over-year CPI. The [policy-rate methodology](https://www.bis.org/statistics/cbpol/cbpol_doc.pdf) distinguishes frameworks and historical instrument changes. We select monthly end-period rates and CPI unit 771, never mix index levels with percentage changes. Singapore is deliberately missing from the policy-rate series. Period labels are not release timestamps.
- [World Bank API](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures) supplies annual GDP growth from 2000. Annual unemployment was independently attempted but timed out during verification; that feed is marked degraded rather than filled with synthetic data.
- [Coin Metrics Community API](https://docs.coinmetrics.io/api/v4/) supplies complete daily active-address, transaction, native-fee and current-supply observations for BTC, ETH, LTC, XRP and XLM. Catalog discovery excludes experimental metrics: Solana experimental entries returned 403 on the free endpoint. There is no access-control bypass. AVAX/SUI lack these free network series.
- [DefiLlama free endpoint reference](https://api-docs.defillama.com/llms-free.txt) documents chain stablecoin histories. Verified `/stablecoincharts/{chain}` responses on `stablecoins.llama.fi` supply Ethereum, Solana, Avalanche, Sui, XRPL and Stellar. Only `totalCirculating.peggedUSD` is used; other pegs have different denominations.

Research collectors run at most daily inside the six-hour core schedule. Each source fails independently and retains last-valid dated observations. Archive requests and ZIP expansion are bounded. Crypto history keeps two years. Direct signals compare fixed 7/30-day calendar windows to their preceding windows, requiring >=80% observations in each and a latest observation within four days. Supply uses change in annualized mean daily log issuance; activity/liquidity use changes in window averages. Tanh scales (20% for activity/liquidity, 2 percentage points for issuance acceleration) are explicit assumptions, not fitted parameters. Activity and fees share a network factor; supply and liquidity receive separate equal factor votes.

Crypto component weights are macro/direct/positioning 45/40/15 short term and 25/40/35 long term, normalized over present components for direction. Coverage retains the missing weights. Conflicting components lower quality and block setup selection. Currency/index macro evidence is grouped and bounded by economic theme; no number of similar releases can create unlimited factor weight. The neutral band avoids treating tiny signed differences as actionable direction.

These changes improve evidence handling, specificity and transparency. Predictive improvement has not been established. An honest return-accuracy study needs archived as-known releases/revisions, executable prices, costs and out-of-sample evaluation. Revised historical macro series are never used to manufacture such a backtest. Shared regional inputs can still produce identical readings for indices; sector earnings, valuations and constituent exposures remain unmeasured.

Verified UI paths include report-family/market/contract filtering, independent horizon narratives, available-instrument-only historical series, direct crypto metrics, and production lazy archive loading. The build leaves the auditable source snapshot intact and splits only the deployed files.
